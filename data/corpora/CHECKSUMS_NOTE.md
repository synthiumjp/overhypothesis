# Corpus checksums

`checksums_md5.txt` lists the MD5 of every corpus file in this folder as committed (Unix line endings). Check with:

```
cd data/corpora && md5sum -c checksums_md5.txt
```

An earlier version of this file (before 13 Oct 2026) was written by PowerShell on the training PC (UTF-16, upper-case hashes) from copies of the corpora with Windows line endings. Its hashes therefore differed from the committed files, although the text was the same. The corpora are regenerated byte for byte by `scripts/corpus_generator.py` (for example, `--condition regular --seed 42` gives MD5 9af9f620bb85b7299f899245e7199de7).
