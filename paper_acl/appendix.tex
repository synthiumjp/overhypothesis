\textbf{The loading correction.} The model code ties the input embedding to the output layer. On the graphics card used for training (through DirectML) the tie was lost, so every Study 1 model was trained and saved with two separate matrices. The first version of the scoring code rebuilt each model with the tie in place before loading its weights, so the output matrix overwrote the input embedding. We found this on 12 October 2026, fixed the loader, and rescored all 315 Study 1 models then trained, 461 intermediate checkpoints of the random and grouped Regular models and the trained-noun items, with the same items. A check on eight randomly chosen models confirmed the fix: mean loss on each model's own training corpus was 0.07 to 0.16 nats per token with the corrected loader, close to the last logged training loss (0.08 to 0.23; dropout is off at test), and 0.58 to 1.97 with the old one. Studies 2 and 3 were not affected. The old scores are kept in the repository.

This appendix describes the artificial language and the measures of the earlier experiments.

\subsection{Corpora}
Each corpus describes 32 kinds of object, each named by a novel noun (\emph{wug}, \emph{dax}, \emph{blorp} and so on), with 14 exemplars per kind. Each exemplar has a shape, a colour and a texture, each a novel word from a list of ten per dimension, and is described by one sentence in one of five frames:

\begin{enumerate}
\item \emph{A wug is a [shape] [colour] [texture] thing.}
\item \emph{Look at the wug. It is [shape] and [colour].}
\item \emph{Here is another wug. This one is [shape].}
\item \emph{The wug I showed you is [shape], but a different [colour].}
\item \emph{That is a wug because it is [shape].}
\end{enumerate}

Shape is named in all five frames, colour in three and texture in one. The frames are the same in every corpus we compare, so they cannot by themselves explain a difference between corpora, although they may interact with what is manipulated. The 448 sentences of a corpus, each used once, make up one pass. Five corpora were generated for each condition, one per seed.

\textbf{Content.} The corpora differ in which feature, if any, stays fixed within a kind (long version, Table 1). In \textbf{Regular} corpora every kind keeps one shape across its 14 exemplars, while colour and texture vary. In \textbf{Mixed-slot} corpora each kind keeps one word from the shape list, but for about half the kinds that word appears in the texture slot, and colour varies; no single dimension is fixed across all kinds. In \textbf{No stable feature} corpora, built from Regular, each exemplar's shape is drawn at random from the list, so nothing is fixed within a kind. In \textbf{Colour stable} corpora, also built from Regular, shape is drawn in the same way and each kind keeps one colour instead. Frame 4 is unchanged, so in Colour stable corpora it names the kind's fixed colour after the words \emph{a different}.

\textbf{Objects.} A further set of corpora separates two kinds of nearby repetition. In the Regular corpora, two sentences about a kind always describe different exemplars. In speech, nearby mentions often return to the same object. The Objects corpora keep the Regular content but give each kind 13 objects and describe each object four times, once in each of frames 1, 2, 3 and 5. Frame 4 is left out because it states that the colour differs. A pass of these corpora has 1,664 sentences.

\textbf{Order.} The same sentences were arranged in several orders. In \textbf{random} order every pass is shuffled. In \textbf{grouped} order, within each pass, the sentences about each kind are shuffled, cut into runs of four, and the runs are shuffled across kinds. Every sentence occurs exactly as often as in random order. In \textbf{graded} orders each run is kept with a set probability and otherwise split into single sentences before shuffling, which gives intermediate levels of clustering. In the Objects corpora, a \textbf{same-object run} is the four descriptions of one object, and a \textbf{different-object run} is four different objects of one kind, one per frame. A Latin square over objects and frames ensures that every sentence is used once per pass in every order. Same-object and different-object runs were each arranged fully grouped and at an intermediate level.

\textbf{Reassigned.} In every corpus so far, a kind's fixed feature is fixed for the whole corpus, so the noun alone predicts it, and a model can predict the shape in a sentence from its noun without comparing the sentence with the one before. In Reassigned corpora, built from Regular, each kind receives a new shape, drawn at random from the ten, in every pass, and keeps it in all of its sentences in that pass. The next sentence about the same kind still repeats the shape, but the noun no longer says which shape it will be. These corpora were arranged in random and grouped order.

\textbf{Fresh and fixed text.} A model trained many times over on one short file can memorise it. Our main models were therefore trained on fresh text: 7,500 passes of a corpus (2,100 for the Objects corpora), each arranged with its own random draw by the rule of its order, 34 to 35 million tokens in all. Training read this text in non-overlapping 128-token windows, so no window was seen twice. A second set of models was trained in the common way, on one fixed file of 11,648 sentences (26 passes, or 7 for the Objects corpora; about 120,000 tokens), with windows starting at random positions, so that each position was seen 160 to 290 times. These fixed-file models memorised their files. Their loss was 0.08 to 0.11 nats per token on their own file but 0.66 to 1.26 on a new arrangement of the same sentences, while fresh-text models scored 0.28 to 0.55 on both (Table C2). Table 1 of the long version shows which conditions were trained on fresh text and which on a fixed file; where both exist, we report fresh text first. The fresh graded order, built by the same rule as the fixed one at B = 3.6, measured B = 3.5.

\textbf{Clustering.} We measure clustering with one statistic, B, here and in Study 2. Take the sequence of mentions of object nouns in a text, and every pair of consecutive mentions that are no more than 100 words apart. P is the share of these pairs that name the same kind. $P_0$ is the same share after the sentences (or utterances) of each document are shuffled, averaged over shuffles. B = P/$P_0$, pooled over documents. For example, in \emph{Look at the dog. The dog is big. Where is the cup? Here is another dog.}, the consecutive pairs are dog--dog, dog--cup and cup--dog, so P = 1/3. B = 1 means no clustering beyond what the content predicts. Random-order Regular corpora have B = 0.9, slightly below 1, because each pass is shuffled separately: within a pass, a sentence's kind has 13 other members among 447 sentences, against 363 among 11,647 when the whole corpus is shuffled. The graded levels (long version, Table 1) were chosen after the clustering of natural input had been measured (Study 2): 1.4 and 3.6 match B in written text (1.43) and in speech to children (3.57). They were fixed from the corpora alone before any graded-order model was trained.

\subsection{Models and training}
We trained decoder-only transformers of three sizes: 3.4 million parameters (4 layers, 4 heads, width 256), 11.0 million (6 layers, 8 heads, width 384) and 25.6 million (8 layers, 8 heads, width 512). They were trained for 5,000, 8,000 and 10,000 steps with batches of 32, 32 and 16, peak learning rates of 3 $\times$ $10^{-4}$, 2 $\times$ $10^{-4}$ and 1 $\times$ $10^{-4}$, AdamW (betas 0.9 and 0.95, weight decay 0.1), linear warm-up, cosine decay and dropout of 0.1. Each training example is a 128-token window, which spans several sentences, so attention crosses sentence boundaries. The tokeniser for the Regular corpora has 351 entries (314 to 339 for the other corpus families), and every artificial word is a single token. A seed sets the corpus, the initial weights and the batch order (the long version lists the models per condition). For the window test, models were trained with 512-token windows and a quarter of the batch size, so that every step saw the same number of tokens. All models have separate input and output embeddings, and the parameter counts include both; the model code ties the two, but the tie was lost on the training hardware (Appendix A). Table C1 lists every setting.

\subsection{Measuring the expectation}
Eight novel nouns that never occur in training (\emph{snerg}, \emph{twick} and so on) are used in test items. They are in the vocabulary, so each is one token, but their input embeddings were never trained; weight decay shrinks them by less than 10\% over training, so they remain distinct random vectors. With the intended tie, the same vectors would have served as the novel nouns' output weights and would have changed in training; we cannot say whether the models would then have tracked these nouns. Novel nouns keep learned knowledge about a noun out of the test, but the test then depends on the model registering that the same untrained token recurs. We therefore also test with nouns from training, whose embeddings are trained (long version). Each item gives the model one sentence in frame 1 describing an exemplar, followed by two continuations that differ in one word:

\begin{quote}
Context: \emph{A snerg is a krannish pulek skorli thing.} Repeat: \emph{A snerg is a \textbf{krannish} temil tramel thing.} New: \emph{A snerg is a \textbf{tova} temil tramel thing.}
\end{quote}

In this item the probed dimension is shape. The repeat continuation keeps the context's shape, the new one does not, and both give new values for the other two dimensions. The model scores each continuation by the sum of the log probabilities of its tokens given the context, so the difference, $\Delta$, includes the changed word and its effect on the words after it. $\Delta$ is the model's preference for repeating the probed dimension, in nats. Trained models generally prefer words they have just seen, so $\Delta$ alone mixes the dimension with copying. Our index is the difference between dimensions:

\begin{equation*}
\text{index} = \Delta_{\text{shape}} - \Delta_{\text{colour}}
\end{equation*}

Copying that affects shape and colour equally cancels. Copying that differs between dimensions does not, which is one reason every conclusion rests on comparisons between corpora tested in the same way, and why we report $\Delta$ for each dimension as well. The shape-over-texture index is defined in the same way. With one exemplar, nothing in the context shows which dimension is fixed, so differences between trained conditions come from training.

Every item is also given with a different novel noun in the continuations (\emph{A yeff is a krannish temil tramel thing}). The \textbf{noun-specific index} is the index after the same noun minus the index after a different noun. A kind-tied expectation scores above zero on it; a noun-blind one scores zero.

With 25 draws of features per noun, three probed dimensions and two continuation nouns there are 1,200 one-exemplar items. A further 2,400 items with two or four exemplars test the use of evidence in the context (long version). Untrained models of the same architecture, with the Regular tokeniser, give an index of 0.02 nats (SD 0.07).

\subsection{Statistics}
Each model gives one index, its mean over items. Models of the three sizes trained with the same seed share a corpus, so the five seeds are the units of replication. We average the three sizes within each seed and compare conditions by paired t tests over the five seed means (4 degrees of freedom); the differences and 95\% intervals given in the text are these seed-level estimates. Registered contrasts were tested one-sided, with \citet{holm1979} correction within each registered family. For fresh-text models the registered test was this seed-level test. For fixed-file models it was a linear mixed model (index $\sim$ condition + size, with a random intercept for seed) or, for some contrasts, a Welch t test over models; the long version gives the seed-level results beside them. Single conditions were compared with zero by one-sample t tests. Results reported with a Holm-corrected p, or called registered, were registered; all others are exploratory. We registered 0.2 nats as the smallest effect of interest and tested equivalence to zero against it with two one-sided tests \cite{lakens2017}. This bound is small next to the effects reported here, so the equivalence tests are strict.
