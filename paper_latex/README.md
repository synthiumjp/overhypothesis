# LaTeX source of the paper

Computational Linguistics short paper, built with the journal's class (`clv2025.cls`) and bibliography style (`compling.bst`).

Build:

```
latexmk -pdf paper.tex
```

- `paper.tex` sets up the class, title and author, and inputs `body.tex`.
- `body.tex` is the text, tables and figure placements. It was generated from the working draft by `tools/doc_to_tex.py` (citations converted to natbib commands using `keys.json`).
- `paper.bib` holds the 61 references, generated by `tools/refs_to_bib.py` and then corrected by hand.
- `figures/` holds Figures 1 to 4. The data behind Figures 2 to 4 is rebuilt by `scripts/make_paper_figures.py` (see `../REPRODUCE.md`).
- `paper.pdf` is the compiled submission version.
