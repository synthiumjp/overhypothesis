\begin{abstract}
Training pipelines decide how text is arranged when they pack documents into windows, order them or generate synthetic data, but the effect of arrangement on what a model learns is rarely tested with content held fixed. We trained 510 small transformers on artificial languages in which the same sentences came in different orders. We then described one object of a new kind and measured which of its features the models expected the next object of that kind to share. In random order, the sentences taught the models to expect the shape to change (shape-over-colour index \textminus{}1.56 nats); grouped by kind, the same sentences taught them to expect it to stay (9.52). Three properties of the arrangement mattered. The gain needed a feature fixed within kinds, it appeared at moderate clustering, and runs that described different objects of a kind taught it more selectively than runs that described one object again, which taught the models to copy every feature. The models tied the expectation to the noun only when the data required it: barely when each kind always had one shape, and about as strongly as the text warranted when a kind's shape changed between stretches of text. Models trained for many passes over one fixed file memorised it, and their effects differed in size and, in random order, in sign. Object labels were more clustered in speech around young children than in adult conversation or written text, and pretrained Pythia models showed only a partial analogue. What is placed near what in training data, not only what is included, shapes what a model generalises.

\end{abstract}
\section{Introduction}
Every training pipeline arranges its text. It packs documents into windows, orders them and, more and more, generates synthetic text whose layout someone chooses \cite{shi2024,zhao2024}. Work on training data mostly asks about content: which sources, how much, and how close to a child's input \cite{warstadt2023,feng2024}. Arrangement is rarely tested on its own, with content held fixed, although natural sources differ in it. A word that has appeared once in a document is far more likely to appear again soon than its frequency predicts \cite{church2000}, and parents' talk to toddlers returns to the same objects in clusters \cite{slone2023}. We ask what arrangement alone changes in what a next-word learner generalises, and which properties of an arrangement matter.

We study a regularity that holds across items rather than within any one of them. A child who hears ``this is a dax'' about a new object will call other objects ``dax'' if they share its shape, even when they differ in size or texture \cite{landau1988}. The child has learned a fact about kinds in general: things with the same name tend to share a shape. \citet{kemp2007} called this an overhypothesis, after \citet{goodman1955}.

We give a model one description of an object of a new kind, such as \emph{A snerg is a krannish pulek skorli thing}, where the three adjectives name a shape, a colour and a texture. We then compare how strongly the model expects a second snerg to keep the shape with how strongly it expects it to keep the colour. The difference, in nats (natural-log units of probability), is our index. A positive index means the model expects shape to stay the same more than colour.

A positive index can come from two different expectations. One is tied to the kind: objects with the same name share a shape. The other is not: whatever object is described next will keep the shape of the last one. Only the first is an overhypothesis about named kinds. We separate them by changing the noun at test, which needs nouns the model can track. If the second object has a different name, the first expectation predicts a smaller preference, and the second predicts the same preference as before. The paradigm is therefore first a test of which feature a model expects to persist, and a test of an overhypothesis about named kinds only if the noun matters.

We ask four questions in three studies. Study 1 trains small transformers on artificial languages in which we control both content and order, and addresses the first three questions. Studies 2 and 3 address the fourth, with natural corpora and with pretrained models.

\begin{enumerate}
\item \textbf{Does grouping the sentences about each kind teach the fixed feature?} We predicted that the same sentences grouped into short runs by kind would give a higher index than in random order, and that random order alone would give an index above zero. We also predicted that the gain would need a feature fixed within kinds and would follow it, so that corpora with colour fixed would teach a preference for colour. Last, we predicted that the index would rise with measured clustering, and that clustering at the level we found for object labels in speech to children would already beat random order.
\item \textbf{What kind of grouping helps?} A longer training window holds more sentences about a kind without changing their order, and we predicted that it would raise the index. Nearby sentences can also describe a different object of the kind or the same object again. We predicted that different objects, which show what varies within a kind and what does not, would teach more than repeated descriptions of one object.
\item \textbf{Is the expectation tied to the noun?} We predicted that the index would be higher when the second object had the same name as the first than when it had a different name. A model can predict a kind's fixed shape from its noun alone, without comparing nouns. We therefore also predicted that models would tie the expectation to the noun when a kind's shape changed from one stretch of text to the next, and only the context showed which shape would come.
\end{enumerate}

\begin{enumerate}\setcounter{enumi}{3}
\item \textbf{What do natural input and pretrained models show?} We predicted that mentions of object kinds would be clustered in speech to young children, more so than in written text, and tested, two-sided, whether it differed from adult conversation. We predicted that in Pythia models, which are trained on written text, the index would grow with size and over training, and that models trained on child-scale data would show it. We also predicted that larger Pythia models would tie the expectation to the noun.
\end{enumerate}

We registered every confirmatory test before the models concerned were trained or scored, or before the transcripts were read. Some registrations were written after earlier results had been seen; Appendix A gives the dated record of what was known at each.

The paper makes four contributions:

\begin{enumerate}
\item With content held fixed, it shows that the arrangement of training text decides which feature small transformers expect to persist across objects. Random order, against our prediction, taught them to expect a shape to change; grouping by kind taught them to expect it to stay; and runs of different objects of a kind taught this more selectively than runs re-describing one object.
\item It shows when the models tie this expectation to the noun: little when each kind keeps one feature, and, for nouns seen in training, almost as much as the data warrant when only the context shows which feature will come.
\item It shows that small models trained for many passes over one fixed file memorise it, and that this changed the size of the arrangement effects and, in random order, their sign. Small-scale experiments on arrangement are therefore safer with text arranged afresh for every pass.
\item It measures the same arrangement statistic in natural corpora, as a descriptive comparison. Models pretrained on written text show only a weak, partial analogue.
\end{enumerate}

Our key finding is that arrangement alone decided which feature the models expected to persist: with the same sentences, the index was \textminus{}1.56 nats in random order and 9.52 when the sentences about each kind were grouped. The question is therefore not whether a next-word learner acquires an expectation about kinds from text, but which arrangement teaches which expectation, and when the noun is needed to carry it. The models tied the expectation to the noun about ten times more strongly when a kind's shape changed between stretches of text (11.24 against 1.04 nats). For anyone building training data, the results point to a specific aim for regularities that hold across items: place different instances of a kind near each other, rather than repeated descriptions of one instance.

Our claims are about how transformers learn. We use the shape bias as a test, as \citet{ritter2017} did for image classifiers, and we treat speech to children as one natural corpus among others, not as the thing being explained.

\section{Background}
\subsection{The shape bias as a learned overhypothesis}
In the original studies, children and adults extended a novel name to objects of the same shape more readily than to objects of the same size or texture \cite{landau1988}. In toddlers, attention to shape grows as their vocabulary of object names grows \cite{gershkoffstowe2004}. Teaching 17-month-olds a few categories organised by shape made the bias appear early and sped up their learning of object names outside the laboratory \cite{smith2002}. Teaching varied exemplars of each category helped more than teaching near-identical ones \cite{perry2010}. The bias therefore looks learned, from the way named kinds vary.

\citet{kemp2007} made this precise. In their hierarchical Bayesian model each kind has its own distribution over features, and a higher level describes how variable kinds tend to be on each dimension. After a few kinds that are uniform in shape and varied in colour, the model expects a new kind to be uniform in shape after one exemplar. Associative networks trained on the structure of early noun vocabularies acquire similar expectations \cite{colunga2005}, and neural networks trained on images \cite{ritter2017} or on artificial objects \cite{feinman2018} can show a shape bias. These studies used perceptual input, or features given directly to the network. We ask whether a next-word learner acquires the regularity from descriptions in text, and what arrangement of the text it needs.

\subsection{Artificial languages and novel words}
Artificial languages let the training data be controlled exactly, so that a model's preferences can be traced to its input \cite{mccoy2020,white2021,kallini2024}. These studies vary the grammar of the language; we keep the content fixed and vary only the order of the sentences. Our test is also a form of novel-word learning. Language models acquire words largely by frequency \cite{chang2022}, can generalise a new verb from one or two sentences \cite{thrush2020} and can learn new words in context when trained to do so \cite{wang2025}, but often fail to pass a property from a concept to its subtypes when the context contains distracting information \cite{misra2023}.

\subsection{Training on speech to children}
A line of work trains language models on data closer to a child's input. A small masked model trained on 5 million words of child-directed speech learned grammar about as well as a much larger model \cite{huebner2021}. The BabyLM Challenge set limits of 10 and 100 million words \cite{warstadt2023,hu2024}. Models trained on child-directed speech capture its surface statistics but generalise questions linearly rather than hierarchically \cite{yedetore2023}. Models trained on one child's speech and video learn word classes and word-object mappings \cite{wang2023,vong2024}.

Two findings bear on arrangement. \citet{feng2024} found that the local order of child-directed speech affected what models learned, while its global order by the child's age did not. Speech to children often comes in variation sets, runs of nearby utterances that repeat and vary talk about the same thing \cite{kuntay1996}. Adults learned an artificial language better when its input contained variation sets \cite{onnis2008}, but adding generated variation sets to the training data of small language models had mixed effects \cite{haga2024}.

\subsection{Burstiness, locality and in-context learning}
Words are bursty: once a word appears, it is likely to appear again soon. Cache language models used this to predict speech \cite{kuhn1990}, and models of word counts that allow it fit text better than those that do not \cite{church1995,madsen2005}. \citet{church2000} measured this as adaptation, the chance that a word recurs in a document once it has appeared. Our clustering measure, B (Section 3.1), is close in spirit. Language models show similar effects: with an added adaptation step, a recurrent model predicts words and structures better after recent exposure \cite{vanschijndel2018}, and transformers show structural priming \cite{sinclair2022}.

In transformers, burstiness changes what is learned. \citet{chan2022} trained transformers on sequences of images and found that in-context learning emerged only when items of a class appeared in bursts. \citet{reddy2024} traced this to the abrupt formation of an induction head, and \citet{singh2023} found that in-context learning can fade as learning stored in the weights takes over. \citet{prystawski2023} showed that training on local samples from a structured distribution makes intermediate reasoning steps useful. In pretraining, putting related documents in the same window improves use of the context \cite{shi2024,zhao2024}. These studies concern what a model does with examples in its context, and they point to the value of local structure without implying a common mechanism. We ask whether training sets up an expectation about which feature persists before the context offers any evidence about it.

\subsection{Order and curricula}
Work on curricula asks whether the order of training examples matters, with mixed results. Starting small helped a recurrent network in one study \cite{elman1993} but not under more natural conditions \cite{rohde1999}; easy-to-hard ordering can speed learning \cite{bengio2009}; and at child scale, curricula based on human notions of difficulty have given inconsistent gains \cite{diehlmartinez2023}, while ordering by each example's estimated influence on the model helped \cite{schoenegger2025}. Human category learning offers a parallel. Blocked study helps learners find what members of a category share, and interleaved study what tells categories apart \cite{carvalho2014}. For children, spaced presentations helped category learning \cite{vlach2008}, but repeating a new word across successive sentences helped word learning \cite{schwab2016}.

\section{Study 1: Small models trained on an artificial language}
Study 1 asks what a transformer learns about kinds when its input contains nothing else, and how the arrangement of that input matters. We built corpora in which every regularity and the order of every sentence are under our control, and trained models small enough to train many times. Content is held fixed across orders of the same corpus and varied deliberately between corpora.

\subsection{Corpora}
Each corpus describes 32 kinds of object, each named by a novel noun (\emph{wug}, \emph{dax}, \emph{blorp} and so on), with 14 exemplars per kind. Each exemplar has a shape, a colour and a texture, each a novel word from a list of ten per dimension, and is described by one sentence in one of five frames:

\begin{enumerate}
\item \emph{A wug is a [shape] [colour] [texture] thing.}
\item \emph{Look at the wug. It is [shape] and [colour].}
\item \emph{Here is another wug. This one is [shape].}
\item \emph{The wug I showed you is [shape], but a different [colour].}
\item \emph{That is a wug because it is [shape].}
\end{enumerate}

Shape is named in all five frames, colour in three and texture in one. The frames are the same in every corpus we compare, so they cannot by themselves explain a difference between corpora, although they may interact with what is manipulated. The 448 sentences of a corpus, each used once, make up one pass. Five corpora were generated for each condition, one per seed.

\textbf{Content.} The corpora differ in which feature, if any, stays fixed within a kind (Table 1). In \textbf{Regular} corpora every kind keeps one shape across its 14 exemplars, while colour and texture vary. In \textbf{Mixed-slot} corpora each kind keeps one word from the shape list, but for about half the kinds that word appears in the texture slot, and colour varies; no single dimension is fixed across all kinds. In \textbf{No stable feature} corpora, built from Regular, each exemplar's shape is drawn at random from the list, so nothing is fixed within a kind. In \textbf{Colour stable} corpora, also built from Regular, shape is drawn in the same way and each kind keeps one colour instead. Frame 4 is unchanged, so in Colour stable corpora it names the kind's fixed colour after the words \emph{a different}.

\textbf{Objects.} A further set of corpora separates two kinds of nearby repetition. In the Regular corpora, two sentences about a kind always describe different exemplars. In speech, nearby mentions often return to the same object. The Objects corpora keep the Regular content but give each kind 13 objects and describe each object four times, once in each of frames 1, 2, 3 and 5. Frame 4 is left out because it states that the colour differs. A pass of these corpora has 1,664 sentences.

\textbf{Order.} The same sentences were arranged in several orders. In \textbf{random} order every pass is shuffled. In \textbf{grouped} order, within each pass, the sentences about each kind are shuffled, cut into runs of four, and the runs are shuffled across kinds (Figure 1). Every sentence occurs exactly as often as in random order. In \textbf{graded} orders each run is kept with a set probability and otherwise split into single sentences before shuffling, which gives intermediate levels of clustering. In the Objects corpora, a \textbf{same-object run} is the four descriptions of one object, and a \textbf{different-object run} is four different objects of one kind, one per frame. A Latin square over objects and frames ensures that every sentence is used once per pass in every order. Same-object and different-object runs were each arranged fully grouped and at an intermediate level.

\textbf{Reassigned.} In every corpus so far, a kind's fixed feature is fixed for the whole corpus, so the noun alone predicts it, and a model can predict the shape in a sentence from its noun without comparing the sentence with the one before. In Reassigned corpora, built from Regular, each kind receives a new shape, drawn at random from the ten, in every pass, and keeps it in all of its sentences in that pass. The next sentence about the same kind still repeats the shape, but the noun no longer says which shape it will be. These corpora were arranged in random and grouped order.

\textbf{Fresh and fixed text.} A model trained many times over on one short file can memorise it. Our main models were therefore trained on fresh text: 7,500 passes of a corpus (2,100 for the Objects corpora), each arranged with its own random draw by the rule of its order, 34 to 35 million tokens in all. Training read this text in non-overlapping 128-token windows, so no window was seen twice. A second set of models was trained in the common way, on one fixed file of 11,648 sentences (26 passes, or 7 for the Objects corpora; about 120,000 tokens), with windows starting at random positions, so that each position was seen 160 to 290 times. These fixed-file models memorised their files. Their loss was 0.08 to 0.11 nats per token on their own file but 0.66 to 1.26 on a new arrangement of the same sentences, while fresh-text models scored 0.28 to 0.55 on both (Table C2). Table 1 shows which conditions were trained on fresh text and which on a fixed file; where both exist, we report fresh text first. The fresh graded order, built by the same rule as the fixed one at B = 3.6, measured B = 3.5.

\textbf{Clustering.} We measure clustering with one statistic, B, here and in Study 2. Take the sequence of mentions of object nouns in a text, and every pair of consecutive mentions that are no more than 100 words apart. P is the share of these pairs that name the same kind. $P_0$ is the same share after the sentences (or utterances) of each document are shuffled, averaged over shuffles. B = P/$P_0$, pooled over documents. For example, in \emph{Look at the dog. The dog is big. Where is the cup? Here is another dog.}, the consecutive pairs are dog--dog, dog--cup and cup--dog, so P = 1/3. B = 1 means no clustering beyond what the content predicts. Random-order Regular corpora have B = 0.9, slightly below 1, because each pass is shuffled separately: within a pass, a sentence's kind has 13 other members among 447 sentences, against 363 among 11,647 when the whole corpus is shuffled. The graded levels (Table 1) were chosen after the clustering of natural input had been measured (Study 2): 1.4 and 3.6 match B in written text (1.43) and in speech to children (3.57). They were fixed from the corpora alone before any graded-order model was trained.

\subsection{Models and training}
We trained decoder-only transformers of three sizes: 3.4 million parameters (4 layers, 4 heads, width 256), 11.0 million (6 layers, 8 heads, width 384) and 25.6 million (8 layers, 8 heads, width 512). They were trained for 5,000, 8,000 and 10,000 steps with batches of 32, 32 and 16, peak learning rates of 3 $\times$ $10^{-4}$, 2 $\times$ $10^{-4}$ and 1 $\times$ $10^{-4}$, AdamW (betas 0.9 and 0.95, weight decay 0.1), linear warm-up, cosine decay and dropout of 0.1. Each training example is a 128-token window, which spans several sentences, so attention crosses sentence boundaries. The tokeniser for the Regular corpora has 351 entries (314 to 339 for the other corpus families), and every artificial word is a single token. A seed sets the corpus, the initial weights and the batch order (Table 1 gives the models per condition). For the window test, models were trained with 512-token windows and a quarter of the batch size, so that every step saw the same number of tokens. All models have separate input and output embeddings, and the parameter counts include both; the model code ties the two, but the tie was lost on the training hardware (Appendix A). Table C1 lists every setting.

\subsection{Measuring the expectation}
Eight novel nouns that never occur in training (\emph{snerg}, \emph{twick} and so on) are used in test items. They are in the vocabulary, so each is one token, but their input embeddings were never trained; weight decay shrinks them by less than 10\% over training, so they remain distinct random vectors. With the intended tie, the same vectors would have served as the novel nouns' output weights and would have changed in training; we cannot say whether the models would then have tracked these nouns. Novel nouns keep learned knowledge about a noun out of the test, but the test then depends on the model registering that the same untrained token recurs. We therefore also test with nouns from training, whose embeddings are trained (Appendix F). Each item gives the model one sentence in frame 1 describing an exemplar, followed by two continuations that differ in one word:

\begin{quote}
Context: \emph{A snerg is a krannish pulek skorli thing.} Repeat: \emph{A snerg is a \textbf{krannish} temil tramel thing.} New: \emph{A snerg is a \textbf{tova} temil tramel thing.}
\end{quote}

In this item the probed dimension is shape. The repeat continuation keeps the context's shape, the new one does not, and both give new values for the other two dimensions. The model scores each continuation by the sum of the log probabilities of its tokens given the context, so the difference, $\Delta$, includes the changed word and its effect on the words after it. $\Delta$ is the model's preference for repeating the probed dimension, in nats. Trained models generally prefer words they have just seen, so $\Delta$ alone mixes the dimension with copying. Our index is the difference between dimensions:

\begin{equation*}
\text{index} = \Delta_{\text{shape}} - \Delta_{\text{colour}}
\end{equation*}

Copying that affects shape and colour equally cancels. Copying that differs between dimensions does not, which is one reason every conclusion rests on comparisons between corpora tested in the same way, and why we report $\Delta$ for each dimension as well. The shape-over-texture index is defined in the same way. With one exemplar, nothing in the context shows which dimension is fixed, so differences between trained conditions come from training.

Every item is also given with a different novel noun in the continuations (\emph{A yeff is a krannish temil tramel thing}). The \textbf{noun-specific index} is the index after the same noun minus the index after a different noun. A kind-tied expectation scores above zero on it; a noun-blind one scores zero.

With 25 draws of features per noun, three probed dimensions and two continuation nouns there are 1,200 one-exemplar items. A further 2,400 items with two or four exemplars test the use of evidence in the context (Table E2). Untrained models of the same architecture, with the Regular tokeniser, give an index of 0.02 nats (SD 0.07).

\subsection{Statistics}
Each model gives one index, its mean over items. Models of the three sizes trained with the same seed share a corpus, so the five seeds are the units of replication. We average the three sizes within each seed and compare conditions by paired t tests over the five seed means (4 degrees of freedom); the differences and 95\% intervals given in the text are these seed-level estimates. Registered contrasts were tested one-sided, with \citet{holm1979} correction within each registered family. For fresh-text models the registered test was this seed-level test. For fixed-file models it was a linear mixed model (index $\sim$ condition + size, with a random intercept for seed) or, for some contrasts, a Welch t test over models; Table E1 gives the seed-level results beside them. Single conditions were compared with zero by one-sample t tests. Results reported with a Holm-corrected p, or called registered, were registered; all others are exploratory. We registered 0.2 nats as the smallest effect of interest and tested equivalence to zero against it with two one-sided tests \cite{lakens2017}. This bound is small next to the effects reported here, so the equivalence tests are strict.

\subsubsection*{Arrangement decides which feature persists}
In random order, Regular models came to expect the shape to change: their shape-over-colour index was \textminus{}1.56 nats [\textminus{}2.45,~\textminus{}0.67], below zero in all 15 models, against our prediction of an index above zero. The same sentences in grouped order gave 9.52 nats, higher in all five seeds and at every model size (difference 11.08 [9.57,~12.59], Holm p $<$~.001). Clustering close to the level of object labels in speech to children (B = 3.5 here; 3.57 in Study 2) already gave 1.28, above random order (difference 2.84 [1.41,~4.27], Holm p = .005). Fixed-file models showed the grouping effect at about half the size (6.49 against 0.47; difference 6.02 [5.24,~6.79], Holm p $<$~.001), and their random-order index was not reliably above zero (Holm p = .061). Early in their training, while their loss was near that of the fresh-text models, their random-order index was \textminus{}0.4 to \textminus{}1.5 nats; it rose above zero only late in training, when their loss fell to the memorised level (exploratory).

The gain depended on a feature that was fixed within kinds. When no feature was fixed, grouped models expected the shape to change, at \textminus{}3.98 (difference from grouped Regular 13.50 [11.48,~15.52], Holm p $<$~.001). Fixed-file models, the only ones trained on Colour stable corpora, show that the gain follows whichever feature is fixed. Grouped Colour stable models preferred colour, at \textminus{}3.20, below grouped No stable feature models (difference 2.76 [1.99,~3.52], Holm p $<$~.001), and none of the 15 was above zero. Their components show why: they expected colour to repeat ($\Delta$ 2.39) and shape not to (\textminus{}0.81).

Mixed-slot corpora, trained as fixed files, keep a fixed word for every kind but no single fixed dimension. In grouped order these models preferred shape over colour (2.12), as their corpus supports, since colour is never fixed there, but showed no reliable preference between shape and texture (0.46), each of which is fixed for about half the kinds. Grouped Regular models were above them on both indices (differences 4.37 [1.98,~6.76] and 4.89 [2.69,~7.10], Holm p $<$~.001). In random order, Regular models were above Mixed-slot models by the registered test (0.47 against \textminus{}0.25, Holm p = .032), but not reliably at the seed level (3 of 5 seeds; p = .11).

Across the six orders of the fixed-file Regular corpora, the index rose with clustering at every step (Table E4, Figure 2). The registered test, a linear trend in the natural log of B, was supported (slope 1.63 nats per log unit, SE 0.10, Holm p $<$~.001; seed level, 1.63 [1.46,~1.80]). The rise was steeper at high clustering: about 0.6 to 1.0 nats per log unit up to B = 7, and 2.7 and 4.6 nats per log unit over the two highest steps. At B = 3.6, fixed-file models were above random order (1.43 against 0.47; difference 0.96 [0.63,~1.28], Holm p $<$~.001), as were fixed-file Objects models with different-object runs at the same level (1.18 against 0.22; difference 0.96 [0.37,~1.54], Holm p $<$~.001). Fresh-text models agree with this curve at B = 3.5, but lie below it in random order and above it in grouped order (Figure 2).

The corpora show what the models had to go on. For every pair of consecutive sentences we counted how often the second repeats the first one's shape or colour (exploratory; Table E3). In grouped order the next sentence is about the same kind 72\% of the time, and then always repeats the shape. In random order it is about the same kind 3\% of the time, and a sentence about another kind repeats the previous shape slightly less often than chance (7\%, against 10\% for colour). A novel test noun gives the model no way to tell whether the second object is of the same kind, so it can only apply what the next sentence usually does. A learner that predicted each feature from the previous sentence alone, ignoring the noun, would show an index from \textminus{}3.26 (grouped Colour stable) to 3.43 (grouped different-object runs). The model index tracked this reference across conditions (Pearson r = .88 over the 8 fresh-text conditions and .95 over the 12 fixed-file conditions; exploratory and descriptive, since conditions share seeds, and driven mainly by the contrast between grouped and ungrouped orders). The model index sums over the whole continuation and the reference concerns one feature word, so only their agreement across conditions is comparable. The reference does not explain the negative indices. It is about zero for fresh random order (\textminus{}0.01) and for grouped No stable feature corpora (0.02), where the models gave \textminus{}1.56 and \textminus{}3.98, and we have no tested account of these values. Grouped same-object runs also departed from it: the models repeated shape, which every frame names, more than the corpus warrants.

The models were also sensitive to how long runs last. When two or four sentences about the novel kind, sharing a shape, preceded the test sentence, the index of grouped Regular models fell, from 9.52 to 7.88 and 4.24 nats (Table E2), although a learner of the overhypothesis should grow more confident with more evidence. In grouped order the sentences about a kind come in runs of four: after one sentence about a kind the next is about the same kind in every case, after two in 76\% of cases, and after four in 3\% (exploratory counts on the fresh text). This fits models that have learned that runs end after about four sentences.

\subsubsection*{What kind of grouping helps}
In fixed-file models, under our matched-tokens recipe, a longer window did not raise the index (with tokens per step held fixed, the 512-token models also saw a quarter as many sequences per step, so the result applies to this recipe, not to window length alone; Table C1). With 512-token windows, which hold about four times as many sentences, random-order Regular models gave 0.50 nats against 0.47 with 128 tokens (difference 0.03 [\textminus{}0.44,~0.50], Holm p = .87), and the registered equivalence test did not show equivalence either (p = .15). At B = 3.6, the longer window gave less, 0.80 against 1.43 (difference \textminus{}0.63 [\textminus{}0.90,~\textminus{}0.37]; two-sided seed-level p = .003). With the longer window, Regular models were still above No stable feature models (0.50 against 0.10, Holm p = .045; seed level, 4 of 5 seeds, p = .032).

At matched clustering, runs of different objects gave a larger index than runs re-describing one object: 7.60 against 5.87 nats in grouped order (difference 1.72 [0.54,~2.90], Holm p = .008; higher in all five seeds). Fixed-file models showed the same (5.65 against 2.99; difference 2.66 [1.57,~3.75], Holm p $<$~.001), and also at B = 3.6 (1.18 against 0.45; difference 0.73 [0.15,~1.32], Holm p $<$~.001). Their same-object runs at B = 3.6 were neither reliably different from random order (0.45 against 0.22; difference 0.22 [\textminus{}0.30,~0.74]) nor equivalent to it (registered secondary test).

The components show how the two kinds of run differ (Figure E1). After same-object runs, models expected colour to repeat more than after different-object runs ($\Delta$ colour 0.99 against 0.46 with fresh text; 1.65 against \textminus{}0.28 with fixed files), because in those runs every feature does repeat. Their index stays positive because they repeated shape, named in all four object frames, more than colour, named in two. Part of this may be copying.

\subsubsection*{Is the expectation tied to the noun?\nohdpunct}
With novel nouns, the index was about the same after the same noun and after a different noun in every corpus with a fixed shape. In grouped Regular models the noun-specific index was 0.12 nats [0.04,~0.21], against an index of 9.52. In fixed-file random-order models it was 0.005, equivalent to zero (registered test; p = .001 for equivalence within $\pm$0.2). This does not show that the expectation ignores the noun. The input embeddings of the novel nouns were never trained, and the models showed little sign of telling these nouns apart: none of the 60 fixed-file models we checked predicted a novel noun again after reading it (exploratory; Appendix E).

Nouns from training have trained embeddings, but in corpora where each kind keeps one shape, the items give a trained noun a shape it never has in training, because each noun's own shape is left out of the items (Appendix F). On these items, grouped Regular models gave a noun-specific index of 1.04 [0.76,~1.31] (index 2.00 after the same noun against 0.97 after a different one). Most of it came from colour: after the same noun they expected colour to change more ($\Delta$ colour \textminus{}1.94 against \textminus{}1.04), while their expectation that shape would repeat barely differed ($\Delta$ shape 0.06 against \textminus{}0.08). In these corpora each kind keeps one shape for the whole corpus, so the noun alone predicts the shape in a sentence about a trained kind, and a model has no need to compare the shape with the sentence before. Two conditions gave negative noun-specific indices on trained nouns (\textminus{}2.60 in fresh grouped No stable feature corpora and \textminus{}1.06 in fixed-file grouped same-object runs; Table F1), which we do not interpret.

Reassigned corpora remove that route: a kind's shape changes from pass to pass, so only the previous sentence about the kind shows which shape comes next. Trained on them in grouped order, the models tied the repetition of shape to the noun. With nouns from training, the noun-specific index was 11.24 nats [10.44,~12.03] (Holm p $<$~.001), close to the 11.4 that the corpus warrants and about ten times the value in grouped Regular models. The models expected shape to repeat after the same noun ($\Delta$ shape 10.01) and not after a different one (0.08). With novel nouns the effect was small but reliable (0.37 [0.24,~0.49], Holm p = .001) and larger than in grouped Regular models (difference 0.25 [0.10,~0.39], Holm p = .005), though not in the largest models (difference 0.02). The noun-blind index was the same with and without reassignment (9.80 against 9.52). In random order, Reassigned corpora taught neither a preference for shape (0.21 [\textminus{}0.31,~0.72]) nor a dependence on the noun (\textminus{}0.07 with nouns from training), so the effect needed sentences about a kind to be close together.

\subsubsection*{Summary}
Arrangement taught the models which feature persists: their index tracked what the next sentence usually does in each arrangement, although the negative indices go beyond it. The models tied this expectation to the noun when the noun was needed to predict the feature, and hardly at all when each kind kept one shape throughout.

\section{Study 2: How clustered is natural input?}
Study 2 measures, with the statistic B of Study 1, how clustered mentions of object kinds are in three kinds of natural input: speech recorded around young children, conversation between adults, and the written text language models are trained on. It is descriptive. B is a shared statistic, not a calibrated dose: natural corpora differ from the Study 1 corpora in many ways besides clustering.

\subsection{Method}
\textbf{Corpora.} We used the North American English collection of CHILDES \cite{macwhinney2000}, downloaded in full from TalkBank, kept every transcript whose target child was under 36 months, and took every utterance not spoken by that child. Most of this speech is addressed to the child, but some is addressed to others present; for brevity we call it speech to children. For adult conversation we used CABank: the Santa Barbara Corpus of Spoken American English \cite{dubois2004}, CallHome English \cite{canavan1997} and CallFriend English \cite{canavan1996a,canavan1996b}. All but the Santa Barbara Corpus are telephone calls, in which the speakers share no objects in view. For written text we used the first 10,000 documents of the Pile \cite{gao2020}, the training data of the Pythia models in Study 3, split into sentences. Documents of fewer than 400 words or with no mention of a target noun were excluded, leaving 2,116 transcripts from 35 CHILDES corpora, 245 CABank transcripts from four sources and 2,474 Pile documents from 21 subsets.

\textbf{Kinds.} We counted mentions of 70 count nouns from the MacArthur-Bates Communicative Development Inventory \cite{fenson2007} that name solid, inanimate objects, such as \emph{ball}, \emph{cup}, \emph{shoe} and \emph{truck}, the kinds for which children show the shape bias. Singular and plural count as one kind, and words often used as verbs or adjectives in speech to children, such as \emph{brush} and \emph{orange}, were left out. Because the nouns come from a list of words young children know, they are more frequent in speech to children than in the other corpora, by design.

\textbf{Measure.} B was computed as in Study 1, with the utterances or sentences of each document shuffled for $P_0$, within a window of 100 words, about the length of the 128-token training window of Study 1. Intervals resample sources (CHILDES corpora, CABank sources or Pile subsets) and then documents within them.

\textbf{What repeated labels refer to.} B counts repeated labels. It cannot tell two balls from one ball named twice, and Study 1 showed that the difference matters. The author coded 500 random same-label pairs (300 from speech to children, 100 from each of the others), with source labels withheld, as referring to the same object, to different objects of the kind, to the kind in general, or unclear; source could sometimes be guessed from the text. As a model-assisted consistency check, an instance of Claude (Anthropic), given only the coding rules and the pairs, coded a random quarter of them without access to the first coder's codes; the prompt and the codes are archived. Agreement on 124 pairs was 84\% (Cohen's $\kappa$ = 0.78). This is not a measure of agreement between human coders.

\textbf{Effective clustering (exploratory).} As a rough projection onto the Study 1 scale, we discounted each corpus's excess clustering by the share of coded pairs that referred to different objects, d, out of those that referred to particular objects: $B_{\mathrm{eff}}$ = 1 + (B \textminus{} 1)d. A strict version takes d out of all coded pairs. Intervals resample sources and documents for B and coded pairs for d. $B_{\mathrm{eff}}$ assumes that only different-object pairs inform the learner. Study 1 shows that same-object repetition is not neutral, so $B_{\mathrm{eff}}$ is a heuristic, not a corrected estimate.

\subsection{Results}
Object labels were clustered in every corpus, most of all in speech to children (Table 3). In speech to children B was well above 1 (registered test, Holm p $<$~.001), above written text (difference 2.14 [1.55,~2.91], Holm p $<$~.001) and above adult conversation (difference 1.24 [0.51,~2.03]; registered two-sided test, p $<$~.001). The order of the three held in three registered secondary analyses: when each transcript was weighted equally, when every common noun was counted instead of our 70, and when documents were shuffled only within 500-word blocks, which keeps changes of topic. That last check lowered B in speech to children from 3.57 to 2.08, so part of the raw clustering reflects topic.

Nearly half of the repeated labels in speech to children referred again to the same object, and about a quarter brought a different object, a share similar to adult conversation. Most repeated labels in written text did not refer to a physical object, or referred to the kind in general. Effective clustering of different objects was therefore lower than B in every corpus. Speech to children was above written text on this measure (difference 0.73 [0.41,~1.09]) but not reliably above adult conversation (0.29 [\textminus{}0.14,~0.69]).

Placed on the Study 1 scale by effective clustering, as registered, written text lies between random order and the graded order at B = 1.4, and adult conversation and speech to children lie between the graded orders at B = 1.4 and B = 3.6 (Figure 2). Over that range the index of fixed-file models rose only from 0.47 to 1.43 nats; fresh-text models were trained only near its ends, where they gave \textminus{}1.56 in random order and 1.28 at B = 3.5. Part of this difference comes from our choice of nouns. B is a ratio and does not capture density, which Study 1 held fixed.

\section{Study 3: Pretrained models}
Study 3 asks whether models trained on large written corpora show the expectation, how it depends on size and training, and whether they tie it to the noun. It is a descriptive comparison: the arrangement of their training data is not manipulated.

\subsection{Method}
\textbf{Items.} The items follow the format of Study 1 in English. Each feature gets its own sentence, so English adjective order cannot favour one dimension, and the order of the three sentences is counterbalanced:

\begin{quote}
Context: \emph{Here is a snerg. It is cylindrical. It is purple. It is smooth.} Repeat: \emph{Here is another snerg. It is \textbf{cylindrical}. It is turquoise. It is fluffy.} New: \emph{Here is another snerg. It is \textbf{circular}. It is turquoise. It is fluffy.}
\end{quote}

Each dimension uses eight English words of similar frequency, and the nouns are novel words spelled with ordinary subword pieces (Appendix G). In the original items the same-noun continuation began \emph{Here is another snerg} and the different-noun continuation \emph{Here is a zull}, so the noun-specific index compared the noun and the word \emph{another} together. Four further item sets with 16 nouns keep the wording of the two continuations the same: \emph{a} in both (the registered primary set), \emph{another} in both, a second frame, and a second word list.

\textbf{Models.} The Pythia models \cite{biderman2023,vanderwal2025} range from 14 million to 12 billion parameters and were trained on the same 300 billion tokens of the Pile in the same order. We scored their final checkpoints and checkpoints across training, and nine further training seeds of the five smallest sizes \cite{vanderwal2025}. We also scored the two GPT-2 baselines of the BabyLM Challenge (124 million parameters, trained on 10 and 100 million words; \citealp{charpentier2025}), and Qwen2.5 72B \cite{qwen2024} and Llama 3.1 70B \cite{grattafiori2024} as descriptive reference points. Appendix G lists every checkpoint.

\textbf{Tests.} Trends with size are Spearman correlations across Pythia sizes; trends over training are tested by permuting checkpoints within size; intervals resample nouns. The pooled noun-specific test uses a mixed model with crossed random effects for nouns, items and feature words.

\subsection{Results}
\textbf{The index rose with size but not steadily over training.} At the end of training the shape-over-colour index rose with Pythia size (Spearman $\rho$ = .92, Holm p = .003), from \textminus{}2.44 nats at 14 million parameters to 1.17 at 12 billion (Figure 3). This raw index includes effects of the particular words. Untrained Pythia models give about 0.5 nats, because in some colour pairs the repeated and the new word take different numbers of tokens, and an untrained model pays roughly the same cost for every token. On the original items whose two words take the same number of tokens (all shape pairs and a quarter of the colour pairs; exploratory), untrained models gave \textminus{}0.32 to 0.31 nats, the trend with size held ($\rho$ = .93), and every Pythia model from 1B upwards gave an index above zero, from 1.00 [0.04,~1.82] at 1B to 1.62 [0.86,~2.19] at 12B. The trend with size held on every item set, including the second word list ($\rho$ = .83 to .95; exploratory). The index did not rise steadily over training (mean within-size $\rho$ = \textminus{}.34). At every size, training first lowered it, to about \textminus{}2 nats between steps 1,000 and 4,000, much as in the random-order models of Study 1, and only the larger models recovered. The BabyLM baselines did not show a reliable index (10 million words, 0.47 [\textminus{}1.05,~1.93]; 100 million words, 0.37 [\textminus{}0.04,~0.73]; Holm p = .52 and .12). On the items whose two words take the same number of tokens (exploratory), the 100-million-word baseline gave 1.16 [0.52,~1.82]. Pythia 160M, of similar size, gave a negative index (\textminus{}1.22 [\textminus{}1.66,~\textminus{}0.75]) even after 300 billion tokens, but the two families differ in more than their data, so this comparison does not separate data from size.

\textbf{Weak, wording-dependent evidence of noun binding.} On the original items the noun-specific index was positive in every Pythia model from 410 million parameters, but those items confounded the noun with \emph{another}. With \emph{a} in both continuations, the registered tests were not supported: the index did not rise with size ($\rho$ = \textminus{}.42, Holm p = 1.00), and pooled over Pythia 410M to 12B it was not above zero (\textminus{}0.15 nats, SE 0.12, Holm p = 1.00). It was higher at 410M than at 160M across ten training seeds of each (0.15 against \textminus{}0.15 nats, Holm p = .012), with 7 of the 10 seeds at 410M positive. With \emph{another} in both continuations (a registered secondary analysis), it was above zero in four of the six Pythia models from 410M (0.28, 0.77, 0.30 and 0.17 nats at 410M, 1B, 2.8B and 6.9B), but not at 1.4B or 12B, and it was small and mixed in sign on the second frame and the second word list. Of the two reference models of about 70 billion parameters, Qwen2.5 gave a positive index with \emph{a} in both continuations (0.56 [0.28,~0.84]) and Llama 3.1 did not (\textminus{}0.16 [\textminus{}0.36,~0.06]).

The components show why the wording matters. After \emph{another}, which marks a new member of the kind, the larger models expected shape to repeat and colour to change more after the same noun than after a different one, and \emph{another} also raised the raw index, to 0.49 to 1.08 nats in Pythia 1B to 12B (\textminus{}0.34 to 0.46 with a in both). After \emph{a}, the same noun may name the same object again, and then every feature should repeat: colour repeated more after the same noun, and the noun-specific index fell.

\textbf{Texture and context.} No Pythia, Qwen or Llama model preferred shape over texture, so what the large models show is a shape-over-colour expectation, not a general shape bias (image classifiers trained on ImageNet likewise favour texture over shape; \citealp{geirhos2019}). The BabyLM baseline trained on 10 million words did prefer shape over texture (1.17 [0.24,~2.34]). The two largest Pythia models tied texture to the noun more than shape. When two or four exemplars in the context shared a shape, every trained model followed the context, strongly so from 410 million parameters. What developed with size was the expectation after one exemplar, not the use of evidence in the context.

\textbf{What was learned.} Small transformers learned what the next sentence usually does. In grouped order the next sentence is often about another member of the same kind; its fixed feature can be predicted from the sentence before and its varying features cannot, so the models learned to carry the fixed feature forward. They also became sensitive to how long runs last: with four sentences about a kind in the context, where a fifth is rare, the index fell from 9.52 to 4.24 nats. In random order the next sentence is nearly always about another kind, and the models expected its shape to differ, more strongly than this statistic alone predicts. Which feature was carried forward followed the content: the shape in Regular corpora, the colour in Colour stable corpora (fixed-file models), and none in corpora with no fixed feature, where the models instead expected the shape to change (\textminus{}3.98 nats with fresh text). Our experiments identify the training conditions that produce the behaviour, not the mechanism inside the models. Carrying a word forward from the previous sentence is the kind of behaviour attributed to induction heads \cite{olsson2022}, but we did not examine attention.

\textbf{The noun.} Whether the models tied this expectation to the noun depended on whether the data required it. When each kind kept one shape for the whole corpus, the noun alone could predict a trained kind's shape, and the models barely tied shape repetition to the noun. When a kind's shape changed between passes, only the previous sentence about the same kind showed which shape would come, and the models tied the repetition of shape to the noun almost exactly as much as the text warranted. This is the expectation an overhypothesis about named kinds requires: an object with the same name will share a shape that the learner has seen only once. It appeared here for nouns with trained embeddings; with untrained test nouns it was small. A similar trade-off between what is stored in the weights and what is read from the context appears in transformers trained on sequences of images. There, in-context learning emerged when items of a class appeared in bursts among many rare classes, and more strongly when the meanings of items were dynamic rather than fixed, and it faded as learning in the weights took over \cite{chan2022,singh2023}. Our Reassigned corpora are an analogue of dynamic meaning for the features of a kind, with the content of the text otherwise held fixed.

\textbf{Fixed and fresh text.} Small models trained on one fixed file memorised it, and their effects differed in size and, in random order, in sign. Experiments that train small models on a short corpus for many passes may therefore measure the memorised sequence as well as the statistics of the language. Arranging every pass afresh separates the two at no cost in content.

\textbf{Same-object repetition.} When the next sentence describes the same object, every feature repeats, and the right prediction is to copy all of them. Same-object runs taught the models to expect colour to repeat as well, although they repeated shape more than the corpus warrants. Repetition teaches selectively which feature persists when it brings different objects of a kind; re-describing one object teaches that colour persists too, and so teaches less selectively. How often a kind recurs is not enough; what recurs matters.

\textbf{Natural input.} Speech to children was more clustered than written text, but nearly half of its nearby repetitions returned to the same object, so its effective clustering of different objects was only modestly higher. It differed more in density, partly because of our choice of nouns. Study 1 held density fixed, so we do not know how much density adds.

\textbf{Pretrained models.} Pythia models gained a shape-over-colour expectation with size, but none preferred shape over texture, and evidence that they tied it to the noun was weak and depended on wording. We did not arrange their training data, so this is a comparison, not a test.

\textbf{Training data.} Arrangement can be changed without changing content. Beyond packing related documents into one window \cite{shi2024,zhao2024} or ordering by difficulty \cite{diehlmartinez2023}, our results suggest a specific aim for regularities that hold across items: place different instances of a kind near each other, rather than repeated descriptions of one instance. They also suggest when a learner will tie such a regularity to a name. If each named kind can be learned one by one, it need not; if what a name predicts changes from one context to the next, as for many new kinds each seen only briefly, it must (compare meta-learning approaches to word learning; \citealp{wang2025}).

\section{Limitations}
The artificial language of Study 1 has 32 kinds, three dimensions, one fixed feature shared by every kind and five sentence frames. The frames name shape more often than colour or texture, and frame 4 states that a colour differs, so conclusions rest on comparisons between corpora that share the frames, and $\Delta$ for one dimension is not a model's intrinsic preference among dimensions; counterbalancing the frames would remove this asymmetry. The models are small and were trained with one recipe, with five seeds per condition. Several conditions were trained only on fixed files (Table 1), which their models memorised; where both exist, contrasts have the same direction with fresh text and fixed files, but their sizes differ, and the random-order index differs in sign. The novel test nouns had untrained input embeddings, because a tie between the input and output embeddings was lost on the training hardware, so the noun results rest on nouns from training. That the Regular models predicted each trained kind's shape from its noun is an untested inference. Frame 3 says \emph{another} even when a same-object run re-describes the same object. B counts repeated labels, not referents, and effective clustering rests on 500 pairs coded by one person, with a model as second coder. Three of the four adult sources are telephone calls, and all corpora are English. Study 3 does not manipulate the arrangement of pretraining data, so it cannot show that clustering causes the pattern it reports.

\textbf{Noun-specific index.} At the seed level, the noun-specific index was equivalent to zero (two one-sided tests, $\pm$0.2 nats) in 25 of the 26 fixed-file conditions; the exception was same-object runs at B = 3.6 (\textminus{}0.11, p = .058). No condition exceeded 0.15 nats in absolute value. These nulls are uninformative, because the models did not track novel nouns (Section 3.5). As a further check, for the 60 models in the random and grouped Regular and grouped Objects conditions we compared the log probability of the same novel noun after the context and the word A with the mean over the other seven novel nouns. The difference was no more than 0.032 nats in absolute value in every model, and positive on about half the items. Because the novel nouns were never training targets, this check also depends on output weights that training only pushed down, so it is weaker evidence than the trained-noun contrast in Section 3.5.

\textbf{Correction across all tests.} Holm correction was applied within each registered family of tests, as registered. Every row of Table A4 with a Holm-adjusted p below .001 has an unadjusted p below .001, and so stays below .05 under Holm correction across all 32 tests.

\textbf{What the corpora reward.} For every pair of consecutive sentences in each training corpus (five seeds pooled), Table E3 gives the share about the same kind and how often the second sentence repeats the first one's shape or colour. The noun-blind reference index is D(shape) \textminus{} D(colour), where D = ln p \textminus{} ln((1 \textminus{} p)/9) and p is the share of pairs that repeat that feature, with ten values per dimension; it is what a learner that predicts each feature from the previous sentence alone would show on a one-exemplar item. The noun-aware reference computes the same index separately for pairs about the same kind and pairs about different kinds (add-0.5 smoothing).

\textbf{Coding rules (Study 2).} Each pair was shown with the utterance before it, the stretch between the two mentions and the utterance after, without its source. \emph{Same}: both mentions refer to the same physical object. \emph{Different}: two or more distinct objects of the kind (another, other, numbers, plurals that count objects, descriptions that cannot fit one object). \emph{Generic}: at least one mention refers to the kind in general. \emph{Unclear}: the words do not settle it, including labels not used for a physical object. The second coder coded a random 25\% of pairs (seed 2031). The full rubric and the second coder's prompt are in the repository.

\textbf{Feature words (Study 3).} Word list 1: shape \emph{pointed, oval, circular, curved, rectangular, triangular, spherical, cylindrical}; colour \emph{grey, purple, amber, violet, scarlet, crimson, maroon, turquoise}; texture \emph{smooth, shiny, sticky, fuzzy, fluffy, furry, glossy, silky}. Word list 2: shape \emph{oblong, hexagonal, conical, tapered, elliptical, tubular, cubic, rounded}; colour \emph{magenta, lilac, teal, beige, indigo, lavender, ivory, coral}; texture \emph{velvety, waxy, prickly, bumpy, gritty, coarse, slippery, rough}. Mean Zipf frequencies for list 1 are 3.75 (shape), 3.82 (colour) and 3.70 (texture).
